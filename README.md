# Math Ponytail

A skill-only plugin that removes low-value definitions and notation from
mathematical writing without changing meaning.

It distinguishes first definitions, notation declarations, reminders, local
scope, and legitimate redefinitions. No application, service, runtime, hook,
or dependency is included.

## Install

Import the marketplace from `hochshi/math-ponytail` at ref
`agent/minimal-math-plugin`, install **Math Ponytail**, and start a new chat.

- ChatGPT: select **Math Ponytail** from the `@` menu.
- Codex: invoke `$ponytail-math`.

Local Codex installation does not automatically install the plugin in ChatGPT.
